# EYERIS OSINT

This directory contains OSINT-oriented launchers and adapters for working with public or otherwise lawfully accessible information.

## Tracker launcher

`run_tracker.sh` launches a local `tracker.py` entry point:

```bash
bash osint/run_tracker.sh
```

Current status: **launcher scaffold only**. The uploaded artifact contained only `python tracker.py`; no `tracker.py` implementation was supplied, so this repository does not yet claim a working tracker.

## Scope

Use this module only for authorized, lawful collection and analysis of public information. Do not use it to bypass authentication, access controls, paywalls, private systems, or other technical restrictions.
